|--------|------|
| `main` | 최종 배포용 |
| `dev` | 통합 개발용 |
| `feat/xxx` | 기능별 개발 |

1. `main`에서 직접 작업 ❌
2. 각자 `feat/기능명` 브랜치에서 작업
3. 작업 완료 → `dev`로 merge
4. 최종 완료 → `main`으로 merge
